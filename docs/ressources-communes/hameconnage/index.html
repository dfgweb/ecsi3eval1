Reconnaître un message frauduleux (hameçonnage)

Date Mon 23 November 2026

L'hameçonnage est la porte d'entrée la plus fréquente : un message imite un correspondant ou un site légitime pour vous faire cliquer, vous authentifier ou payer.

Les signaux qui doivent alerter

  • L'urgence. « Sous 24 h », « votre compte sera suspendu », « dernier rappel » : la pression est l'outil principal de l'attaquant.
  • L'adresse de l'expéditeur. Regardez le domaine réel, pas le nom affiché : comptabilite@fournisseur-securise.com n'est pas fournisseur.com.
  • Le lien. Survolez-le sans cliquer : l'adresse réelle diffère souvent du texte affiché.
  • La demande. Identifiants, mot de passe, changement de RIB, virement, pièce jointe à ouvrir : aucun organisme sérieux ne demande cela par courriel.
  • La pièce jointe. Facture, bon de commande ou « document » inattendu, surtout en .zip, .html ou .exe.
  • Le ton. Un message qui ne ressemble pas à ceux de votre correspondant habituel, ou qui mélange les langues.

Que faire

  1. Ne cliquez pas, n'ouvrez pas, ne répondez pas.
  2. Signalez le message selon la procédure interne.
  3. Si vous avez déjà cliqué ou saisi vos identifiants : changez le mot de passe et signalez-le immédiatement.

Le cas des SMS et des appels

Le principe est le même : un message ou un appel qui réclame un code, un mot de passe ou un paiement est suspect. Raccrochez et rappelez l'organisme à un numéro que vous connaissez déjà.
