Sauvegardes : les principes

Date Mon 23 November 2026

Une sauvegarde n'a de valeur que si elle permet de redémarrer l'activité. Un rançongiciel chiffre les données — et souvent aussi les sauvegardes accessibles depuis le réseau.

Les principes

  • Trois copies, deux supports, une hors ligne. La copie hors ligne (ou immuable) est celle qui survit à un rançongiciel : si elle est montée sur le réseau, elle sera chiffrée comme le reste.
  • Testez la restauration. Une sauvegarde jamais restaurée n'est pas une sauvegarde. Planifiez un test réel et mesurez la durée de reprise.
  • Chiffrez les supports, en particulier s'ils sont transportés ou externalisés.
  • Séparez les droits : le compte qui écrit la sauvegarde ne doit pas pouvoir l'effacer.

Que sauvegarder

  • Les données métier : base patients, dossiers, logiciel métier et sa configuration.
  • Les comptes et les paramétrages, pas seulement les fichiers.
  • Les données hébergées chez un prestataire : vérifiez qui sauvegarde quoi, et que l'hébergement est certifié HDS pour les données de santé.

Ce qu'il faut vérifier

  1. La fréquence correspond-elle à ce que vous pouvez perdre ?
  2. Le délai de restauration est-il compatible avec l'arrêt d'activité tolérable ?
  3. Qui déclenche la restauration, et comment, un jour où le prestataire est injoignable ?
